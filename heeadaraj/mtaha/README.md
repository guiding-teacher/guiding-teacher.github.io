# 🌀⚔️ متاهة الهروب — حرب المتاهة

لعبة سباق ومتاهة **وقتال مباشر** لـ 2 أو 4 لاعبين، من نفس عائلة «الحية والسلم» ونفس
مشروع Supabase ونفس حساب الملف الشخصي (`snl_user_id` و جدول `profiles`).

## 🎮 فكرة اللعبة
- عند إنشاء الغرفة يختار المنشئ **عدد اللاعبين (2 أو 4)** ومستوى الصعوبة.
- **نظام التماثل الهندسي المعمّم** (الابتكار الأساسي): بدل توليد متاهة عشوائية بسيطة،
  تُبنى ١/k من الشبكة فقط (نطاق واحد) بخوارزمية حفر عشوائي بذرة ثابتة بدءًا من الهدف
  المركزي، ثم تُنسخ بقية النسخ عبر **دوران هندسي متكرر 90°** حول المركز:
  - **ثنائي (k=2):** نسخة واحدة مُدارة 180° (نفس مبدأ "المرآة").
  - **رباعي (k=4):** ثلاث نسخ إضافية مُدارة 90°/180°/270°، فتُصبح المتاهة رباعية التماثل.
  النتيجة: **كل نقاط انطلاق اللاعبين على نفس المسافة بالضبط من الهدف** رياضيًا، بصرف
  النظر عن عددهم — عدالة مُثبَتة وليست تقديرية (راجع `test_symmetry_math.js`).
- 👮 حرّاس متحركون مكرَّرون بنفس عدد اللاعبين وبنفس التزامن الزمني (بلا أي حركة شبكة).
- 🔫 **قتال حقيقي:** اجمع ذخيرة 🔫 من الأرض، اضغط زر الإطلاق لإطلاق النار في اتجاه
  حركتك الأخيرة عبر الممر المستقيم المفتوح (Raycast حقيقي عبر جدران المتاهة).
  إصابة خصم تُفقده ❤️ وتعيده لبدايته؛ الدرع 🛡 يصدّ الرصاص كما يصدّ الحرّاس.
- ⭐ مكافآت (سرعة/درع/كشف/تجميد) و🕳️ فخاخ — موزّعة بنفس النمط المتماثل بين كل اللاعبين.
- ❤️❤️❤️ ثلاث قلوب: نفادها = إقصاء من الجولة (لكن الجولة تستمر لبقية اللاعبين في وضع الرباعي).
- 🌀 **منطقة آمنة متقلّصة** (بأسلوب الحرب الملكية Battle Royale): بعد ~55٪ من وقت الجولة
  تبدأ المنطقة الآمنة (حول الهدف) بالانكماش تدريجيًا؛ البقاء خارجها يكلفك قلبًا كل ثوانٍ
  قليلة — يُجبر مواجهات حاسمة قرب النهاية بدل الاختباء الدائم.
- 🏆 **الفوز:** الوصول للهدف أولًا، أو أن تكون **آخر الصامدين** إن أُقصي البقية، أو
  الأقرب للهدف عند انتهاء الوقت.
- ⚔️ إشعار متحرك **"بدأت الحرب!"** يظهر فور اكتمال جميع الفتحات مباشرة قبل بدء الجولة.
- 📡 **كشف المغادرة التلقائي** عبر Supabase Presence: إن أغلق أحد اللاعبين المتصفح أو
  فقد الاتصال، يُعتبر مُقصًى تلقائيًا دون الحاجة لأي إجراء من البقية.
- 🩸 خلاصة إصابات حيّة (Kill Feed)، اهتزاز الشاشة عند الإصابة، أثر رصاص مضيء، وشريط
  لاعبين ديناميكي (2 أو 4) بحالة حياة وتقدّم كل لاعب لحظيًا.
- 🧭 بوصلة اتجاه محدودة الاستخدام، وشاشة نتائج نهائية بترتيب كل اللاعبين.

## 📁 الملفات
| الملف | الوصف |
|---|---|
| `index.html` | هيكل الصفحة وكل الشاشات (بما فيها شاشة "بدأت الحرب" والنتائج) |
| `style.css` | التصميم — نفس هوية الحية والسلم + أنماط القتال والشرائط متعددة اللاعبين |
| `app.js` | كل منطق اللعبة: التماثل الهندسي، الحرّاس، القتال، الشبكة، المنطقة الآمنة |
| `schema.sql` | جدول `maze_rooms` (حتى 4 لاعبين) + دوال RPC آمنة (شغّله في Supabase) |
| `test_symmetry_math.js` | إثبات رياضي مستقل لعدالة التماثل الهندسي k=2 و k=4 |
| `test_engine.js` | اختبار الحرّاس المكرَّرين ونظام الرماية (Raycast) |

## 🚀 خطوات التركيب
1. Supabase Dashboard → **SQL Editor** → New query → الصق `schema.sql` بالكامل ونفّذه.
   (آمن للتشغيل حتى لو كان لديك جدول `maze_rooms` من نسخة سابقة أحادية الثنائي فقط —
   السكربت يضيف الأعمدة الناقصة تلقائيًا عبر `add column if not exists`.)
2. تأكد أن **Realtime** مفعّل على `maze_rooms` (السكربت يفعّله تلقائيًا).
3. ارفع `index.html` و`style.css` و`app.js` إلى نفس مكان استضافة لعبة الحية والسلم.
4. افتح `index.html` — سيُستخدم ملفك الشخصي تلقائيًا من نفس الجهاز.

## ✅ تحقّق تم إجراؤه بالفعل
- `node test_symmetry_math.js`: اتصال كامل 100٪، صفر تعارضات جدران، وتماثل تام في
  مسافة الانطلاق بين كل نقاط البداية — لكل من الوضعين الثنائي والرباعي وكل مستويات الحجم.
- `node test_engine.js`: صحة تكرار مسارات الحرّاس (k نسخة متطابقة الطول)، وصحة مدى
  ومسار نظام الرماية (Raycast) عبر الممرات المفتوحة فقط.
- تدقيق صياغة `app.js` بالكامل (`node --check`) دون أخطاء.
- تطابق كل معرّفات عناصر الواجهة (id) المستخدمة في `app.js` مع ما هو موجود في `index.html`.

## 🧠 ملاحظات تصميم مهمة
- **تصحيح جوهري في المنطق:** عند انتهاء الوقت أو الإقصاء الفردي في وضع الرباعي، لا
  تُنهى الجولة تلقائيًا لأول لاعب يُقصى أو يظن نفسه الأقرب — كل جهاز يحسب محليًا (عبر
  المواقع المُتبادلة بالبث اللحظي) **من هو فعليًا الأقرب/آخر الصامدين**، ويُبلّغ فقط
  صاحب الاستحقاق الفعلي، بينما تضمن دالة `report_maze_result` عبر `SECURITY DEFINER`
  أن أول إبلاغ صالح فقط هو الذي يُعتمد (يمنع أي تلاعب أو ازدواجية نتائج).
- المغادرة الفردية في وضع الرباعي لا تُنهي الجولة — تُعلن ذلك اللاعب مُقصًى فقط
  (عبر بث + Presence)، وتستمر المعركة بين الباقين.

## 🔧 أفكار توسّع مستقبلية (اختيارية)
- ربط XP/الإنجازات بنفس نظام الحية والسلم لمشاركة تقدّم موحّد بين اللعبتين.
- أوضاع أسلحة متعددة (قذيفة مرتدة عن الجدران، رشاش سريع منخفض الضرر).
- بطولات "أفضل من 3 جولات" بتبديل نقاط الانطلاق بين الجولات لعدالة إضافية.
